# CYBER//CORE — Cyborg Landing Page

A futuristic, responsive landing page designed around a **cyborg / human-machine interface** concept. The design combines modern web aesthetics with interactive HUD elements, neon accents, animations, and responsive layouts.

## 🚀 Live Demo

https://drive.google.com/drive/folders/1v0OeOBh3ZPBVeYAwfQEhqlOw3viF7x3-?usp=sharing

## 📌 Project Overview

CYBER//CORE is a concept landing page for a fictional cybernetic technology company focused on human augmentation and advanced human-machine interfaces.

The website was designed with a dark futuristic aesthetic and includes interactive elements inspired by sci-fi operating systems and cybernetic interfaces.

## ✨ Features

* Fully responsive design
* Futuristic cyborg-inspired UI
* Interactive custom cursor
* Animated HUD interface
* CSS-generated cyborg visual
* Animated system statistics
* Interactive 3D card hover effects
* Mouse-based parallax effects
* Smooth scrolling navigation
* Animated scanning effects
* Responsive mobile navigation
* Interactive buttons and hover states
* Modern typography and grid-based layout

## 🛠️ Technologies Used

* **HTML5** — Page structure and semantic markup
* **CSS3** — Styling, responsive design, animations, and visual effects
* **JavaScript** — Interactions, animations, counters, navigation, and mouse effects

## 📱 Responsive Design

The website is optimized for:

* Desktop
* Laptop
* Tablet
* Mobile devices

The layout, typography, navigation, cards, and visual elements automatically adapt to different screen sizes.

## 🎨 Design Direction

The visual language is inspired by:

* Cybernetic interfaces
* Futuristic HUD systems
* Human-machine integration
* Advanced technology
* Minimal dark interfaces
* Neon digital displays

The primary visual palette uses dark neutral tones with cyan and subtle violet accents to create a futuristic technological atmosphere.

## ⚙️ How to Run

No installation or dependencies are required.

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` using a browser.

For the best development experience, you can use the **Live Server** extension in VS Code.
